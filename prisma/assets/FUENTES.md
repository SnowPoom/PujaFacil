# Imágenes del catálogo académico

El catálogo utiliza fotografías diferentes de Wikimedia Commons y Unsplash. Las imágenes se conservan localmente para que la exposición no dependa de Internet.

El archivo `catalog.json` registra para cada imagen el enlace original, autor y licencia. Los nombres, precios, propietarios, procedencias y estados del seed son datos sintéticos de un caso académico ecuatoriano. Las imágenes ilustran los expedientes y no constituyen una oferta de venta de los objetos reales fotografiados.

Las fichas de identidad creadas por el seed son material académico sintético sin validez oficial.
